# Knowledge Base

Private notes on agent-specific internals discovered during development.
This directory is gitignored except for this README.

Files here document reverse-engineered behavior, minified symbol mappings,
config keys, and workarounds. They are NOT part of the published package.

## Files

- `behavior-contracts.md` — runtime behavior patterns of supported agents
- `minified-symbols.md` — minified function/variable name mappings (with versions)
- `config-keys.md` — agent-specific env vars and config keys
- `workarounds.md` — each workaround: one line + commit hash + file:line
